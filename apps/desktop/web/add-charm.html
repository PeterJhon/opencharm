添加挂件

第 1 步，共 4 步

让它连接到这台电脑

你做的挂件通过这个应用经 Wi-Fi 连接到你的智能体。打开 此网络上的挂件，然后用 USB 插上挂件。

macOS 会询问 OpenCharm 能否发现本地网络上的设备，以及（防火墙开启时）“node”能否接受传入连接：那是 OpenCharm 的 charmd。两次都选择允许。错过了？在 系统设置 → 隐私与安全性 → 本地网络 中允许 OpenCharm，并在 系统设置 → 网络 → 防火墙 → 选项 中允许 node，然后退出并重新打开 OpenCharm。

第 2 步，共 4 步

连接到你的 Wi-Fi

  1. 挂件的屏幕会显示 Wi-Fi 名称 OpenCharm-… 和密码。用手机加入那个网络并输入密码。
  2. 会打开一个页面（或访问 192.168.4.1）。选择你的 Wi-Fi（2.4 GHz），输入密码。
  3. 其余保持原样：挂件会自己找到这台电脑。
