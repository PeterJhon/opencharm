# fonts

Sources for the LVGL bitmap fonts in `../src/ui/fonts/` (generated by `npm run firmware:fonts`; never edit the `.c` or `.bin` files).

| File                           | Use                                | Licence                                                                                  |
| ------------------------------ | ---------------------------------- | ---------------------------------------------------------------------------------------- |
| `GeistMono-ExtraBold.ttf`      | face glyphs, pairing digits        | SIL OFL 1.1 (`OFL-Geist.txt`), [vercel/geist-font](https://github.com/vercel/geist-font) |
| `GeistMono-Medium.ttf`         | text lines, PIN pad, hints         | SIL OFL 1.1 (`OFL-Geist.txt`)                                                            |
| `NotoSansSymbols2-Regular.ttf` | only `♥` (Geist Mono has no heart) | SIL OFL 1.1 (`OFL-Noto.txt`), [google/fonts](https://github.com/google/fonts)            |
| `NotoSansSC-Medium-subset.ttf` | Chinese text in the C fallback     | SIL OFL 1.1 (`OFL-NotoSansSC.txt`), [google/fonts](https://github.com/google/fonts)      |
| `NotoSansSC-Medium.otf`        | the board's full CJK font source   | SIL OFL 1.1 (`OFL-NotoSansSC.txt`), [google/fonts](https://github.com/google/fonts)      |

`common-chinese.txt` holds the 3,778 characters of GB2312 level-1 plus Chinese punctuation that the
C fallback is subset to. `charm_cjk_24.c` is the generated LVGL font at 24 px (6.7 MB of source,
about 1 MB in the firmware); it is the fallback of both `charm_text_24` and `charm_text_35` in the
emulator and the host tests, so a Chinese line on the speech font draws the 24 px glyphs (spec 016).

`charm_cjk_24_full.bin` is the board's full font: every CJK character in GB18030's BMP (Extension
A, Unified Ideographs, Compatibility Ideographs) plus CJK punctuation and fullwidth forms, at
24 px, generated from `NotoSansSC-Medium.otf`. It is 7.3 MB and lives in the app image; the board
reads glyphs from flash on demand (`lv_binfont_create_ex` with `dynamic_glyph_load`), never copying
the font to RAM. The board's app partition is 11 MB for it (spec 016); the emulator and host tests
keep the small C font, so they still show only the 3,778 common characters.
